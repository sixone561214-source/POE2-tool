# Sample Input

The skill should support any of these input forms.

`BD_SUMMARY.md` refers to the final BD summary report.

## Video URL

```text
请分析这个 POE2 BD 视频，并生成 BD_SUMMARY.md：
https://www.bilibili.com/video/xxxx
```

## Local Video

```text
请分析这个本地视频，并生成 BD_SUMMARY.md：
<path-to-your-video-file>
```

## Transcript + Notes

```text
下面是视频转写和作者 POB 链接，请生成 BD_SUMMARY.md。

转写：
...

POB：
...
```

## Screenshots + POB

```text
我已经提供技能截图、装备截图和 POB 链接。请总结这套 BD。
```
