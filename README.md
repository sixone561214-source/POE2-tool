# POE2 Tool

本仓库包含一个用于《流放之路2》BD 视频分析的共享 Codex Skill。

This repository contains a shared Codex Skill for reviewing Path of Exile 2 BD/build videos.

它可以把 BD 视频、逐字稿、截图、POB、poe.ninja 样本或作者说明，整理成一份玩家能直接看懂的 BD 总结报告。

It turns BD videos, transcripts, screenshots, POB links, poe.ninja samples, or author notes into a clear player-facing BD review report.

## Included Skill

- `poe2-bd-video-analyzer/`

使用场景：当你提供 POE2 BD 视频、逐字稿、截图、POB 链接、poe.ninja 样本或作者笔记，并希望生成清晰的 BD 总结报告时使用。

Use this Skill when you provide a POE2 BD video, transcript, screenshots, POB link, poe.ninja sample, or author notes and want a clear player-facing BD review report.

这个 Skill 可以只基于文字和截图工作。自动下载、转写和关键帧提取需要自行准备 `yt-dlp`、`ffmpeg`、本地转写工具等可选工具。

The Skill can work from text and screenshots alone. Automatic video download, transcription, and keyframe extraction require optional local tools such as `yt-dlp`, `ffmpeg`, and a local transcription tool.
