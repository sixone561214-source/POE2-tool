# POE2 Tool

This repository currently contains a shared Codex Skill for analyzing Path of Exile 2 BD/build videos.

## Included Skill

- `poe2-bd-video-analyzer/`

Use this Skill when you provide a POE2 BD video, transcript, screenshots, POB link, poe.ninja sample, or author notes and want a clear player-facing BD summary report.

The Skill can work from text and screenshots alone. Automatic video download, transcription, and keyframe extraction require optional local tools such as `yt-dlp`, `ffmpeg`, and a local transcription tool.

## Download Package

- `poe2-bd-video-analyzer-share-v1.zip`

The zip contains the same Skill folder for direct download or installation.
